# weather-app
Project Overview

Weather App is a simple web application that shows real-time weather information for any city using a weather API. It displays temperature, humidity, wind speed, and weather conditions.

This project was built for learning and practice purposes.

Features

Search weather by city name
Real-time weather updates
Temperature, humidity, and wind speed display
Clean and responsive UI
Tech Stack
HTML
CSS
JavaScript
Weather API
